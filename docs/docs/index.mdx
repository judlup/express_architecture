# Express Architecture — Documentación

Bienvenido al sitio de documentación sobre **prácticas de arquitectura empresarial orientadas a la toma de decisiones**. Usa los enlaces rápidos para navegar por las secciones principales del proyecto:

- **[Fundamentos Conceptual-Teóricos](./fundamentos/)**: Prácticas situadas, Información Mínima Suficiente (IMS), ajuste cognitivo y objetos frontera.

- **[Changelog](./changelog/)**: Historial de evolución de la investigación y la documentación.
